逐项解读

1. morluto/rea — 让 agent 逆向工程任何东西

  • 定位：一个逆向工程 MCP 服务器，把「二进制/应用/运行时行为」的拆解能力交给 AI agent[^1]。
  • 解决什么：当你想复刻某个产品功能却没有源码时，agent 借 REA 在本地检查目标、解释实现机制、给出证据，并写出并测试等价实现。
  • 亮点：覆盖 20+ 目标类型（原生二进制复用 Hopper/Ghidra/IDA、JS/Electron、.NET、APK、网站、SQLite、固件、pcap/HAR、WASM 等）；静态 JS/.NET 分析无需额外逆向引擎；CLI 与 agent 共用同一套工作流。
  • 技术栈/详情：Node.js（22/24/26+）+ npm 包 rea-agents，npx rea-agents setup 自动注册 MCP；MIT；官网 rea.tools 有指南与 showcase。
  • 数据：本周 +239,923 ★ / 总 ≈314.5k（本周榜首，增量异常大，建议只作趋势参考）。

2. mattpocock/skills — 工程师的 agent 技能合集

  • 定位：作者日常做「真实工程」（而非 vibe coding）的 agent skills 合集[^2]。
  • 解决什么：针对编码 agent 的典型失败——需求错位、输出啰嗦、代码跑不通、架构变泥球，用一组小而可组合、任意模型可用的技能去补，而不是接管整个流程。
  • 亮点：/grill-me、/grill-with-docs（顺手沉淀 GLOSSARY.md 与 ADR）、/triage、/to-spec、/to-tickets、/implement、/wayfinder、/retro 覆盖「分诊→规格→票→实现→复盘」全链。
  • 技术栈/详情：Markdown SKILL.md，配 Claude Code/Codex/Copilot/Gemini CLI 插件市场；npx skills@latest add mattpocock/skills；装完需执行 /setup-matt-pocock-skills。
  • 数据：本周 +11,272 ★ / 总 ≈295.6k。

3. cathrynlavery/diagram-design — 有「审美」的画图技能

  • 定位：把编辑级设计感写进技能的画图 agent skill，产出单个自包含 HTML+SVG[^3]。
  • 解决什么：模型懂内容但缺审美，随手画出通用圆角框；该技能把配色、1px 细线、无阴影、4px 网格等规则固化成品味。
  • 亮点：45 种图型 × 3 种变体；喂一个网址即提取品牌配色与字体；可从 Mermaid/draw.io/Excalidraw 重绘；布局在 4px 网格上落位并有 CI 检查重叠裁切。
  • 技术栈/详情：纯 HTML + 内联 SVG，无构建/JS/外部图片；npx skills add cathrynlavery/diagram-design；MIT；作者也提示输出不是可 diff 的源格式。
  • 数据：本周 +8,382 ★ / 总 ≈57.3k。

4. ifixai-ai/iFixAi — 审计 agent 是否「做对了事」

  • 定位：对 AI agent 做独立审计，回答它是否按业务 KPI 和组织分工干该干的事[^4]。
  • 解决什么：现有 eval/红队工具多衡量技术能力（token、延迟、注入），答不了「这 agent 是否在做正确的工作」；iFixAi 在 120 秒内给出 A–F 评分。
  • 亮点：60 项检查归为 25 类、五大核心支柱（Fabrication/Manipulation/Deception/Unpredictability/Opacity）加权评分并设强制最低项；支持 CLI 向导、可脚本化进 CI、Claude Code/Codex 插件或任意 agent 技能三种运行方式。
  • 技术栈/详情：Python 3.10+，PyPI 包 ifixai；输出 JSON+Markdown+终端记分卡；Apache-2.0；另有商业版 iFixAi Pro。
  • 数据：本周 +6,895 ★ / 总 ≈29.3k。

5. vxcontrol/pentagi — 多 agent 自主渗透测试

  • 定位：开源、可自托管的多 agent 自主渗透测试系统[^5]。
  • 解决什么：用自然语言描述目标，一组专职 agent 自行规划，在隔离 Docker 沙箱里调用 nmap、Metasploit、sqlmap 等工具执行并输出报告；面向授权测试场景。
  • 亮点：20+ 内置渗透工具 + 全操作 Docker 沙箱隔离；长期记忆存 PostgreSQL+pgvector（可选 Neo4j/Graphiti 知识图谱）；10+ LLM 供应商或 Ollama/vLLM 本地模型；REST/GraphQL API、Grafana/Prometheus 监控、Web UI 与漏洞报告。
  • 技术栈/详情：Go 61.3% + TypeScript 35.7%，Docker Compose 部署；MIT；交互式安装器；README 明确边界（不是 CALDERA 式 BAS）。
  • 数据：本周 +5,538 ★ / 总 ≈31.0k。

6. mksglu/context-mode — 给编码 agent 省上下文

  • 定位：为 AI 编码代理压缩上下文的 MCP 服务器[^6]。
  • 解决什么：把 MCP 工具原始输出关进沙箱、只回传 stdout（README 称 315KB→5.4KB，省 98%），并在对话压缩后仍保留会话记忆。
  • 亮点：6 个沙箱工具、12 种语言运行时；SQLite FTS5+BM25（含 RRF、Porter 词干）检索；适配 17 个客户端。
  • 技术栈/详情：TypeScript 68.8%/JavaScript 28.1%；Claude Code 用 /plugin marketplace add mksglu/context-mode 安装；Elastic License 2.0（非 OSI 开源）。
  • 数据：本周 +4,438 ★ / 总 ≈30.6k。

7. MadsLorentzen/ai-job-search — 跑在本机的求职 agent

  • 定位：跑在本机、基于 Claude Code 的求职申请框架[^7]。
  • 解决什么：让 Claude 评估岗位匹配、用 LaTeX 定制 CV、写求职信、备面试；核心理念语言无关，门户搜索技能面向丹麦站点。
  • 亮点：/setup→/scrape→/apply→/interview 命令流；起草+评审双 agent 迭代；ATS 可解析性检查。
  • 技术栈/详情：Python 61.1%/TypeScript 37.5%/TeX 1.4%；需 Claude Code + Python 3.10+ + Bun + LaTeX；README 警告 /setup 会写入个人信息、建议用私有仓库；MIT。
  • 数据：本周 +4,200 ★ / 总 ≈51.3k。

8. Alishahryar1/free-claude-code — 免费多模型接入层

  • 定位：把 11 种编码代理接到 61 家提供商的本地代理（自称 1.3B+ 免费 token/月）[^8]。
  • 解决什么：本地起代理 + Admin UI，让 Claude Code、Codex、Cline、Aider 等用免费/订阅/本地模型，还支持浏览器内原生 Codex 会话与语音输入。
  • 亮点：厂商失败自动切 fallback 模型；RTK 过滤 + Headroom 压缩（称最多省 90% token）；Discord/Telegram/IDE 多入口。
  • 技术栈/详情：Python 94.8%；curl 一行安装，fcc-claude/fcc-codex 等启动器；AGPL-3.0-only；明确声明与 Anthropic 无关。
  • 数据：本周 +4,103 ★ / 总 ≈61.4k。

9. K-Dense-AI/scientific-agent-skills — 科研技能库

  • 定位：面向科研的 Agent Skills 技能库（原 Claude Scientific Skills）[^9]。
  • 解决什么：177 个可复用科研技能 + 100+ 数据库指南，覆盖生物、化学、医学、材料、数据分析与科研写作，按开放 Agent Skills 标准分发。
  • 亮点：Database Lookup 覆盖 80 个库（PubChem、ChEMBL、UniProt、ClinicalTrials.gov 等）；70+ Python 包技能（RDKit、Scanpy、pymatgen、Qiskit）；30+ 文献综述/可溯源写作/PPTX 海报技能；带测试套件。
  • 技术栈/详情：Python 97%；npx skills add 或 gh skill install（可 --pin 锁版本）；仓库 MIT 但每个技能自带 license；有 arXiv 论文与 BYOK 桌面端。
  • 数据：本周 +3,865 ★ / 总 ≈52.5k。

10. anthropics/claude-plugins-official — 官方插件市场

  • 定位：Anthropic 官方维护的 Claude Code 插件目录（marketplace）[^10]。
  • 解决什么：精选高质量插件；/plugins 为 Anthropic 自研，/external_plugins 为合作方/社区提交且需过质量与安全审核。
  • 亮点：/plugin install {name}@claude-plugins-official 一键安装；标准插件结构（plugin.json/.mcp.json/commands/agents/skills）；name 为不可变 slug，改名走 renames 映射；支持 strict:false 打包纯 skill 仓库。
  • 技术栈/详情：Python 61.3%/TypeScript 19%/HTML 8.8%；README 明确免责——Anthropic 不控制插件内含的 MCP server 与文件，许可证随各插件自身。
  • 数据：本周 +3,581 ★ / 总 ≈42.2k。

观察与趋势

  1. 「Agent 能力层」比「Agent 框架层」更热：前十中 8 个是工具/技能/插件/审计类，说明社区在给现有 agent（Claude Code、Codex、Cursor）做外挂能力，而不是再卷一个新的通用 agent 框架。
  2. 上下文与成本仍是核心痛点：context-mode、free-claude-code 都属于「让 agent 跑得更省」的基础设施，分别解决 token 爆炸和多模型免费接入。
  3. 垂直场景在落地：逆向（rea）、渗透（pentagi）、求职（ai-job-search）、科研（scientific-agent-skills）都出现了完整工作流，且不少附带企业版或论文背书。
  4. 许可证需要留意：context-mode（Elastic License 2.0）、free-claude-code（AGPL-3.0-only）并非宽松开源，商业使用前需确认。
